# The original GeMoSC

The original GeMoSC corpus (75 films, 2018 to 2021) was created by Balestrucci, Dusek,
Anselma, and Mazzei and introduced in:

> Can Large Language Models Personalize Dialogues to Generational Styles?
> Findings of the Association for Computational Linguistics: EMNLP 2025, pages 64 to 77.

It is not re-hosted here. The authors release their data and code under CC BY 4.0 at
https://github.com/PierBale/P-MultiWoZ, where the original corpus is in the `GeMoSC`
folder. That version uses four cohorts (Baby Boomer, Generation X, Generation Y, and
Generation Z) over films released from 2018 to 2021.

This repository (the parent of this folder) is an extension of that corpus, not a copy of
it. The extension covers a different, non-overlapping period (2008 to 2017) and a larger
set of films (896), annotated with the same scheme, and adds two older cohorts (Silent
and Lost Generation) that the earlier films make relevant.
