# Annotation guidelines

The annotation of this extension followed the guidelines of the original GeMoSC, given in
the appendix of Balestrucci et al. (2025), without modification.

- **Human characters only.** Include only human characters. Exclude non-human characters
  (for example animals in animated films) and voice roles. This is why animated films are
  excluded from the analysis.
- **Use the actor's age when the character's age is unspecified.** If the script does not
  state the character's age, use the actor's age as a reference, on the reasoning that a
  performer of a given age generally speaks in a way consistent with a character of that
  age.
- **Contemporary or clearly datable settings.** Favor films set in modern or easily
  datable settings, where a character can be assigned to a specific generation. Avoid
  films set in historical periods or ambiguous timelines.
- **Clear character identification.** The character's role and name must be matchable to
  an IMDb entry without ambiguity.
- **Single age representation.** Exclude characters portrayed at more than one age within
  the same film.

The generation label is not annotated by hand. It is derived from the actor's recorded
year of birth by a fixed rule:

| Cohort | Birth years |
|---|---|
| Lost Generation | before 1928 |
| Silent Generation | 1928 to 1945 |
| Baby Boomer | 1946 to 1964 |
| Generation X | 1965 to 1980 |
| Millennial | 1981 to 1996 |
| Generation Z | 1997 to 2012 |
| Generation Alpha | 2013 and later |
